# PLC Traceability Matrix Template

Use this template when generating the matrix. Replace all `<placeholder>` values
with derived content. Status values are exactly `COVERED`, `PARTIAL`, `GAP`.

Save the rendered matrix to `agentic_plc/work_products/<feature-name>/traceability.md` in workspace mode, otherwise `.plc/briefs/<feature-name>-traceability.md`.

## Status Application Reminders

- Apply the status rules in `SKILL.md` → *Status Vocabulary* exactly. `GAP` always wins when Code is empty; tests against missing implementation are still gaps.
- A path-only Code cell (no `:line`) demotes the row to `PARTIAL`. Never invent a line number.
- A `(stale)` marker on Last verified demotes a row that would otherwise be `COVERED` to `PARTIAL`.

## Sorting Reminder

The matrix is **one flat table**, not one table per requirement type. Type grouping appears in the *Coverage Summary* table. Reviewers consuming the matrix as CSV need one continuous table.
